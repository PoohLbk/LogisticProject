# LogisticProject
This project implements a mathematical optimization model using Gurobi to minimize the total costs in a three-tier supply chain network: Plants, Distribution Centers (DCs), and Retailers.
Key Components:
Plants (P1–P3): Supply sources with specific production capacities.  

Distribution Centers (D1–D6): Intermediate hubs with handling costs, storage capacities, and operational status (Open/Closed).  

Retailers (R1–R11): End destinations with specific product demands.
